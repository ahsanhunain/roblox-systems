# roblox-systems

Luau systems from games I've worked on at [DOODLEWOOD Games](https://doodlewoodgames.com/).

* [session-save](session-save/) - DataStore saving with session locking
* [ragdoll-knockback](ragdoll-knockback/) - ragdoll + knockback for players
* [egg-hatching](egg-hatching/) - egg hatching with luck and pity
* [rebirth-economy](rebirth-economy/) - coins, upgrades, selling and rebirths

Used in [Last Town Zombie Escape](https://www.roblox.com/games/85958529399721/UPD-LAST-TOWN-Zombie-Escape), [Find and Evolve Monsters](https://www.roblox.com/games/104146074760099/Find-Evolve-MONSTERS) and [Octopus Energy Tycoon](https://www.roblox.com/games/114201343561910/Octopus-Energy-Tycoon).
